## 해석

- 새싹: 9/9 클리어. 인수인계의 “거의 모두 클리어” 목표와 이번 표본은 맞는다.
- 도전: 2/9 클리어(22%). 목표 약 40%보다 이번 표본은 낮다. 실패 7판 중 6판은 내포 지역 보스, 1판은 보령 중간 보스에서 종료됐다.
- 전설: 3/9 클리어(33%). 나머지 6판은 3~5지역에서 종료됐다. 도전보다 클리어가 많지만, 무작위 가호·동료·갈림길 선택과 소표본 때문에 난이도 역전으로 단정할 수 없다.
- 먼저 조합별 판 수를 늘려 도전 최종 보스 구간과 기체별 편차를 확인하는 것이 좋다. 이번에는 DIFFS·BOSSES 수치를 바꾸지 않았다.
- 실제 학생 플레이는 봇의 즉각적인 탄막 회피와 다르므로 학생 난이도까지 검증한 결과는 아니다.

## 재실행

브라우저 설치가 가능한 환경에서는 원래 안내대로 실행한다.

```bash
python -m http.server 8765
python -m pip install playwright
python -m playwright install chromium
python tools/balance.py 3
```

이번 환경에서 사용한 대체 실행:

```bash
node tools/balance-node.mjs 3
```

무작위 실행이라 재실행하면 결과가 달라진다. 상세 로그는 `balance-results.json`에 있다.
