### 한 판의 흐름

```
타이틀 → 기지(격납고) → 파일럿 선택 → 기체 선택 → 난이도 선택
  → [지역 1~5 반복]
      웨이브1 → 웨이브2 → 중간 보스 → AI 12지신 동료 고르기 → 웨이브3 → 지역 보스
      → 예방 수칙 카드 획득 → 수호신 제단(가호 3택1)
  → 결과(코인 정산) → 기지
```

## 2. 조작

| 입력 | 동작 |
|---|---|
| 드래그 (터치·마우스 누른 채) | 기체 이동, 손가락 위치를 상대 이동으로 따라감 |
| 손 떼기 / 마우스 버튼 놓기 | 슬로우 모션 (게임 속도 감소, 화면 테두리 푸른 효과) |
| 키보드 방향키·WASD | 이동, 아무 이동키도 안 누르면 슬로우 |
| 필살기 버튼 / Space | 게이지 100%일 때 발동 |

- 공격은 항상 자동 발사.
- 슬로우 배율은 난이도별로 다르다 (5장 참고).

## 3. 파일럿과 기체

파일럿은 **패시브**, 기체는 **공격 방식과 필살기**를 맡는다. 3 × 3 = 9가지 조합.

### 3-1. 파일럿

| 파일럿 | 체력 | 패시브 | 해금 |
|---|---|---|---|
| 충남이 | 100 | 기본탄 강화: 발사 수 +1, 탄속 +20% | 처음부터 |
| 센터이 | 80 | 속성 피해 강화: 가호의 속성 피해 +30%, 상태이상 지속 +1초 | 공주 첫 클리어 |
| 에듀이 | 120 | 보호막: 12초마다 적 탄 1발을 막는 방패 생성 | 보령 첫 클리어 |

### 3-2. 기체

| 기체 | 기본 공격 | 필살기 | 성격 |
|---|---|---|---|
| 별빛호 | 속사 기관포 (초당 8발, 발당 10) | **별빛 파동**: 화면의 적 탄 전부 소거 + 전체 피해 | 무난·위기 탈출 |
| 드론호 | 기관포 (초당 5발, 발당 8) + 유도 드론 2대 (드론당 초당 2발 유도탄) | **드론 편대**: 드론 6대가 5초간 돌격 | 회피에 집중하는 유도형 |
| 번개호 | 관통 레이저 (초당 3발, 발당 24, 무한 관통) | **거대 광선**: 3초간 전방 굵은 광선 | 보스 저격 |

- 필살기 게이지: 적 처치로 충전. 지역 하나에 2~3번 쓸 수 있는 양 (일반 적 2%, 정예 8%, 중간 보스 30%).
- 추천 조합 안내 (선택 화면 문구): 충남이+번개호 "보스 화력형", 에듀이+드론호 "생존형", 센터이+별빛호 "가호 조합형".

## 4. 성장 체계

판 안의 성장은 두 경로, 판 밖의 성장은 기지에서 한다.

```
경험치 → 레벨업 → [무기 / 강화] 3택1   (참고 이미지 방식, 각 5칸)
지역 클리어 → 수호신 제단 → [가호] 3택1  (하데스 방식)
코인 → 기지 → 영구 강화·해금
```

### 4-1. 레벨업: 무기와 강화

- 무기 5칸, 강화 5칸. 같은 것을 다시 고르면 레벨이 오른다 (최대 Lv.5).
- 무기 Lv.5 + 짝이 되는 강화 보유 → 다음 레벨업에 **진화** 선택지 등장.

| 무기 | 효과 | 짝 강화 | 진화 |
|---|---|---|---|
| 기본 무기 강화 | 기체 기본 공격 피해 +20%/Lv | 연사 속도 | 기체별 궁극형 (별빛 폭풍 / 드론 군단 / 플라스마 창) |
| 유도 미사일 | 2초마다 유도 미사일 | 쿨타임 감소 | 군집 미사일 |
| 산탄포 | 부채꼴 5발 | 탄 크기 | 벌집 산탄 |
| 궤도 위성 | 기체 주위 회전체 | 지속 시간 | 위성 고리 |
| 폭탄 투하 | 앞쪽에 터지는 폭탄 | 피해 범위 | 집속 폭탄 |
| 부메랑 | 갔다 돌아오는 칼날 | 탄속 | 회오리 부메랑 |

| 강화 | 효과 /Lv |
|---|---|
| 공격력 | +10% |
| 연사 속도 | +8% |
| 탄속 | +10% |
| 쿨타임 감소 | −6% |
| 탄 크기 | +10% |
| 피해 범위 | +10% |
| 지속 시간 | +12% |
| 최대 체력 | +15 (즉시 회복) |
| 자석 범위 | +25% |
| 치명타 | +5% 확률 |

### 4-2. 수호신 가호

- 지역 보스를 쓰러뜨리면 제단이 열리고, **무작위 수호신 3명**이 가호를 하나씩 제안한다.
- 가호에는 등급이 있다: 일반(흰색) · 희귀(파랑) · 영웅(보라). 등급이 높을수록 수치가 크다.
- **슬롯 규칙** (하데스 방식): 가호 종류 중 **탄환**·**슬로우** 칸은 한 개만 가질 수 있고, 새로 고르면 교체된다. 나머지는 계속 쌓인다.

| 종류 | 설명 | 칸 |
|---|---|---|
| ① 탄환 | 기본 공격에 속성 부여 | 1개 (교체) |
| ② 자동 스킬 | 일정 주기로 저절로 발동 | 제한 없음 |
| ③ 피격 반응 | 맞았을 때 발동 | 제한 없음 |
| ④ 슬로우 | 슬로우 모션 중 효과 | 1개 (교체) |
| ⑤ 궤도 | 기체 주위를 도는 오브 | 제한 없음 |

#### 속성 상태이상

| 수호신 | 속성 | 상태이상 |
|---|---|---|
| 계룡 | 번개 | **감전**: 맞은 적에서 주변 2마리로 연쇄 피해 |
| 금강 | 빙결 | **냉기**: 감속 15%, 3번 쌓이면 1.5초 빙결 |
| 서해 | 파도 | **밀림**: 넉백 + 탄 관통 |
| 백제 | 불꽃 | **화상**: 3초간 초당 지속 피해 |
| 칠갑 | 바람 | **질풍**: 연사·회피 강화 (적보다 나를 강화) |
| 태안 | 빛 | **가호**: 회복·보호막 (생존 담당) |

### 4-3. AI 12지신 수호대 (동료)

중간 보스를 쓰러뜨리면 12지신 중 무작위 3마리가 나오고, 1마리를 골라 **그 지역 끝까지** 기체 옆에서 함께 난다. 다음 지역에서 새로 고른다. 처음 고른 동물은 AI 역량 카드로 카드첩에 남는다.

| 동물 | 쉬운 말 (원래 키워드) | 도움 |
|---|---|---|
| 쥐 | 바르게 쓰기 (윤리) | 4초마다 주변 적 탄 소거 |
| 소 | 끝까지 해내기 (끈기) | 쓰러질 공격 1회 버티기 |
| 호랑이 | 기본 실력 (핵심역량) | 공격력 +25% |
| 토끼 | 널리 나누기 (확산) | 기본 탄 2갈래 추가 |
| 용 | 넓게 보기 (고차원) | 3초마다 가장 강한 적에 하늘 광선 |
| 뱀 | 길 찾기 (방향) | 0.8초마다 유도탄 |
| 말 | 나눠 정리하기 (범주) | 5초마다 가로 돌진 |
| 양 | 최고를 향해 (최고) | 치명타 +15% |
| 원숭이 | 새롭게 생각하기 (창의성) | 6초마다 무작위 속성 폭발 |
| 닭 | 때를 맞추기 (타이밍) | 필살기 게이지 자동 충전 |
| 개 | 믿고 지키기 (신뢰) | 10초마다 보호막 +1, 체력 3 회복 |
| 돼지 | 아껴 쓰기 (재정) | 코인 2배 |

상표명(구글·크롬 등)은 게임에 넣지 않는다.

### 4-4. 갈림길과 정예 적

- 웨이브 1 뒤와 웨이브 3 뒤(지역 보스 앞)에 갈림길이 나오고, 아래 5개 중 2개를 보고 고른다.

| 길 | 효과 |
|---|---|
| 💰 코인 길 | 다음 웨이브 코인 2.5배 |
| 💖 쉼터 길 | 체력 35% 회복 (회복 금지 계약이면 안 나옴) |
| 📘 수련 길 | 다음 웨이브 경험치 1.6배 |
| ✨ 가호 길 | 작은 제단: 수호신 2명 중 한 명의 가호 |
| ⚔️ 정예 길 | 정예 적 2마리 추가 (보스 앞에서는 안 나옴) |

- 정예 적: 웨이브 2부터 60% 확률로 1마리. 체력 7배, 금테와 왕관 표시. 잡으면 보물 상자(레벨업 1회 + 코인 10).

### 4-5. 도전 계약

한 번이라도 최종 클리어하면 출격 전에 고를 수 있다. 여러 개를 함께 걸 수 있고 코인 보너스가 더해진다.

| 계약 | 조건 | 코인 |
|---|---|---|
| 💨 빠른 탄막 | 적 탄 속도 +25% | +20% |
| 🛡️ 단단한 적 | 적·보스 체력 +40% | +25% |
| 🚫 회복 금지 | 모든 회복 없음 (부활 가능) | +25% |
| 😡 보스 분노 | 보스 패턴 30% 빠름 | +20% |
| ✌️ 좁은 제단 | 제단 선택지 2개 | +15% |
| 🧍 혼자 비행 | 12지신 동료 없음 | +15% |

## 7. 기지 (판 밖 성장)

| 메뉴 | 내용 |
|---|---|
| 영구 강화 | 코인으로 단계 강화 (아래 표) |
| 격납고 | 파일럿·기체 선택, 잠긴 파일럿의 해금 조건 표시 |
| 가호 도감 | 가호 30 + 듀오 10 + 전설 6, 얻어 본 것만 그림과 설명 공개 |
| 카드첩 | 지역 상식 5 + SW·AI 개념 6 + 예방 수칙 10 + AI 역량 12 = 33장 |
| 설정 | 효과음, 배경음, 진동, 기록 초기화, 교사 모드 |

| 영구 강화 | 단계 | 효과 /단계 |
|---|---|---|
| 기본 공격력 | 10 | +3% |
| 최대 체력 | 10 | +5 |
| 자석 범위 | 5 | +10% |
| 시작 코인 보너스 | 5 | 판 종료 코인 +5% |
| 제단 다시 뽑기 | 3 | 판마다 리롤 1회 |
| 부활 | 1 | 판마다 1회 체력 50%로 부활 |

### 이어하기

- 수호신 제단에서 가호를 고르면 판 상태(지역, 체력, 무기·강화·가호, 코인, 필살기 게이지)를 자동 저장한다.
- 타이틀과 기지에 **이어하기** 버튼. 이어하면 다음 지역 웨이브 1부터 시작한다.
- 판이 끝나거나(사망·최종 클리어) 새 판을 시작하면 저장이 지워진다.
- 수업 1차시(40분)에 2~3지역, 다음 차시에 나머지를 하는 흐름을 기준으로 한다.

### 교사 모드

- 설정 화면 맨 아래 버전 글자를 7번 누르면 비밀번호 입력 칸이 나타난다. 비밀번호는 선생님께 따로 안내(코드에는 암호만, `src/save.js` TEACHER_HASH).
- 켜면 이 기기에서 파일럿 3명·지옥 난이도·카드 33장·도감이 모두 열리고, 아무 지역에서나 시작할 수 있다.
- 끄면 원래 기록으로 돌아간다 (교사 모드는 학생 기록을 덮어쓰지 않음).

### 카드 구성

| 종류 | 획득 | 예시 |
|---|---|---|
| 지역 상식 5 | 지역 첫 클리어 | 아산 현충사·온양온천 / 공주 공산성·무령왕릉 / 부여 정림사지 오층석탑 / 보령 머드축제·대천해수욕장 / 내포 충남도청·충남교육청이 있는 신도시 |
| SW·AI 개념 6 | 수호신 가호 첫 획득 | 계룡=반복문(연쇄), 금강=조건문(멈춤), 서해=데이터 흐름, 백제=알고리즘(순서), 칠갑=네트워크(전달), 태안=인공지능(판단) |
| 예방 수칙 10 | 보스 첫 처치 | 6장 표 참고 |

카드 문구는 3줄 이내, 초등 고학년이 읽을 수 있는 수준으로 쓴다.

### 정화 퀴즈

보스를 정화하면 '정화 완료' 도장 → OX 퀴즈 1문제(맞히면 코인 +15, 틀려도 해설) → 예방 수칙 카드 순서로 나온다. 보스 10종마다 1문제.

### 오늘의 도전

날짜로 파일럿·기체·적 배치·선택지 난수가 정해지는 판. 도전 난이도 고정, 이어하기 없음. 기지에 오늘 내 최고 기록 표시. 학급이 같은 조건으로 겨루고 이야기 나누기용.

### 수업 시간 모드

교사 모드 설정에서 10·15·20·30분을 고르면 그 기기에 저장된다(교사 모드를 꺼도 유지). 전투 화면 왼쪽 위에 남은 시간이 보이고, 시간이 되면 '오늘은 여기까지!' 결과와 오늘 배운 카드 목록을 보여 준다.

### 이야기 조각

출격 횟수, 첫 패배, 보스 정화, 12지신 동료, 오늘의 도전, 도전 계약 등 조건을 채우면 판이 끝날 때 한 번에 최대 2개씩 열린다. 15개, 카드첩 아래에서 다시 볼 수 있다.

### 설치형(오프라인)

`manifest.webmanifest` + `sw.js`. 한 번 접속하면 게임 파일을 기기에 저장해 와이파이 없이도 실행된다. 태블릿 브라우저의 '홈 화면에 추가'로 앱처럼 설치. 파일 목록이 바뀌면 `sw.js`의 VERSION을 올린다.

## 9. 기술 구조

- 빌드 도구 없음. ES 모듈로 나눈 순수 JavaScript + Canvas 2D. GitHub Pages에 그대로 배포.
- 기존 `index.html`은 `legacy/neon-blaster.html`로 보존.
- 저장은 `localStorage` (실패해도 게임은 동작).
- 게임 시간은 `dt × timeScale`로 계산해 슬로우 모션과 일시정지를 한곳에서 처리.
- 가호·무기·보스·카드는 전부 `data/` 폴더의 표 형식 데이터. 항목 추가는 데이터 한 줄 + 효과 함수 하나.

```
index.html            화면 틀
style.css             모든 화면 스타일 (참고 이미지 기준 UI)
src/
  main.js             화면 흐름, 전투 루프, 카드·제단·결과 연결
  battle.js           전투 엔진: 플레이어·적·보스 패턴·무기·가호 효과
  render.js           전투 화면 그리기 (그림 파일 없으면 임시 그림)
  progress.js         레벨업 선택지, 수호신 제단 선택지
  ui.js               타이틀·기지·선택·HUD·일시정지·레벨업·제단·카드·결과
  assets.js           그림 로더 + 임시 그림
  input.js view.js audio.js save.js
  motion.js           화면 모션 (모션 견본집)
  bgart.js            움직이는 배경 (흐름장)
data/
  content.js          파일럿·기체·난이도·지역·적·보스·카드·영구 강화
  build.js            무기·강화·진화
  boons.js            수호신·가호·듀오·전설
  zodiac.js           AI 12지신 동료
  extras.js           갈림길·정화 퀴즈·도전 계약·이야기 조각
assets/img/ sfx/ bgm/ 그림·소리 (파일 이름은 docs/chatgpt-brief.md)
legacy/neon-blaster.html  예전 게임
docs/DESIGN.md        이 설계서
```

### 그림 자동 교체 규칙

`assets/img/` 에 지시서 파일명(예: `pilot_chungnami.png`, `boss_scroller.png`)으로 넣으면 다음 실행부터 해당 그림을 쓰고, 없으면 코드로 그린 임시 그림을 쓴다. 가호 아이콘 시트(가로 5칸)는 자동으로 잘라 쓴다.
