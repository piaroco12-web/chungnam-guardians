# 보안 범위 (2.12.2)

- **게임 코드는 공개**: 학생 브라우저가 내려받아 실행하므로 JS·그림은 누구나 볼 수 있다. 비밀은 코드에 두지 않는다.
- **교사 모드**: 설정 맨 아래 버전 글자 7번 → 교사 비밀번호. 코드에는 SHA-256 암호(`src/save.js` TEACHER_HASH)만 있다. 교사 모드는 화면 잠금 해제 용도이고 학생 기록 서버 권한과는 상관없다.
- **순위표 읽기**: 구글 시트 Apps Script의 READ_KEY(선생님만 앎)가 있어야 읽을 수 있다. READ_KEY는 시트에만 있고 저장소에는 예시 문구만 있다.
- **학생 계정**: 비밀번호(숫자 4자리)는 기기에서 SHA-256으로 바꿔 보낸다. 시트에는 암호만 저장, 5번 틀리면 10분 잠금. 기기에는 로그인 유지를 위해 암호를 저장한다(나가기·다음 학생 준비 때 지움).
- **기록 보내기**는 누구나 보낼 수 있는 창구라 시험·평가 점수 근거로 쓰지 않는다. 시트 수식 주입(= + - @)은 서버가 막는다.
- 공개 사이트(Pages)에는 `_config.yml`로 docs·tools·art-src를 올리지 않는다(저장소에서는 보인다).
