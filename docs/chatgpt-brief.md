# 충남 수호대 — ChatGPT 작업 지시서 (2026. 10. 24. 개정)

이 문서는 교육용 세로형 슈팅 로그라이크 게임 '충남 수호대'의 그림·음원 작업 지시서야. 이전 대화에서 받은 지시와 다른 부분은 이 문서를 기준으로 해 줘.

## 이번에 바뀐 내용

1. **캐릭터와 기체를 분리**: 이전의 '캐릭터+비행기' 그림 대신 파일럿 3명(비행기 없이 캐릭터만)과 기체 3종을 따로 만든다.
   - 파일럿: 충남이(기본탄 강화), 센터이(속성 피해 강화), 에듀이(보호막)
   - 기체: 별빛호(속사, 필살기 탄막 소거), 드론호(유도 드론, 필살기 드론 편대), 번개호(관통 레이저, 필살기 거대 광선)
   - 예전 파일명 `char_*_portrait.png`, `ship_chungnami/centeri/edui.png`는 더 이상 쓰지 않는다.
2. **보스 10종 전부 사용**: 지역 보스 5종 + 지역 중간 보스 5종.
3. **필살기 버튼 3종**을 파일럿이 아닌 기체 기준으로 변경.
4. 이미 만든 수호신·가호 아이콘·적·배경·UI 그림은 그대로 써도 된다.

## 게임 구조 요약

- 대상: 초·중학생, 세로형 화면, 터치·마우스·키보드
- 진행: 아산 → 공주 → 부여 → 보령 → 내포 5지역. 지역마다 웨이브1 → 웨이브2 → 중간 보스 → 웨이브3 → 지역 보스 → 수호신 제단(가호 3택1)
- 수호신 6: 계룡(번개)·금강(빙결)·서해(파도)·백제(불꽃)·칠갑(바람)·태안(빛). 가호 30 + 듀오 10 + 전설 6
- 파일럿 3 × 기체 3 = 9가지 조합, 손을 떼면 슬로우 모션
- 난이도: 새싹·도전·전설 + 지옥(전설 클리어 시 해금)
- 보스는 무섭지 않은 귀여운 악당이고, 처치하면 정화되어 착한 모습이 된다

| 지역 | 중간 보스 | 지역 보스 |
|---|---|---|
| 아산 | 레벨업 블랙홀 (게임 과몰입) | 무한스크롤러 (숏폼 중독) |
| 공주 | 대필봇 (AI 과의존·표절) | 딥페이커 (딥페이크·가짜뉴스) |
| 부여 | 악플 먹구름 (사이버폭력) | 따돌림 가시덩굴 (학교폭력) |
| 보령 | 잭팟 슬롯킹 (사이버도박) | 피싱 문어 (개인정보·피싱) |
| 내포 | 스모그 대왕 (기후위기) | 폭주 AI 코어 (AI 윤리, 최종) |

## 작업 규칙

- 아래 '공통 스타일'을 모든 그림에 똑같이 적용한다.
- 각 항목의 파일명 그대로 PNG로 만든다. 게임 소재는 투명 배경 1024×1024, 배경은 1024×1792. 항목에 크기가 따로 적혀 있으면 그 크기를 따른다.
- 한 번에 한 장씩 만들고, 다음 항목으로 넘어가기 전에 내 확인을 기다린다.
- 음악·효과음 항목은 그림이 아니라 웹 검색으로 무료 음원을 찾아 표로 정리하는 작업이다.

### 공통 스타일

> [공통 스타일] 한국 모바일 세로형 슈팅 게임용 아트. 밝고 채도 높은 카툰 스타일, 두껍고 진한 외곽선, 부드러운 셀 셰이딩, 통통하고 귀여운 2~3등신 비율, 초등·중학생 대상이라 무섭지 않고 유쾌한 분위기. 실제 기관 로고·실존 인물·기존 게임 캐릭터는 넣지 말 것. 이미지 안에 글자는 넣지 말 것(따로 지시한 경우 제외).

```
같은 게임에 쓸 효과음을 웹에서 찾아 줘. 조건은 CC0 우선(없으면 CC BY), 짧은 ogg 또는 wav, 한 파일 200KB 이하.

필요한 효과음
- 기본 총알 발사(가볍고 반복해도 안 거슬리게), 적 피격, 적 폭발(작게/크게)
- 코인 획득, 경험치 획득, 레벨업, 카드 선택 확정
- 번개, 얼음, 파도, 불꽃, 바람, 빛 속성 스킬 각 1개
- 필살기 발동, 보스 등장 경고음, 플레이어 피격, 버튼 클릭

출력 형식: 표 (효과음 | 파일명 | 사이트 | 직접 링크 | 라이선스 | 표기 문구). 여러 개를 한 번에 받을 수 있는 묶음 팩이 있으면 먼저 알려 줘.
```
