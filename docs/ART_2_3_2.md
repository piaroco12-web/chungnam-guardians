# 그림·메뉴 개선 2.3.2

- 영구 강화 6종: 기존 입체 전용 그림 연결 유지. 구형 화면이 남는 문제를 줄이기 위해 새 서비스 워커 설치 시 HTTP 캐시를 재사용하지 않고 메뉴에서 새 제어기가 활성화되면 한 번 갱신한다. 전투·출격 선택 중에는 강제 갱신하지 않는다.
- 듀오 가호 10종: 두 수호신 초상 대신 각 조합을 하나의 입체 속성 그림으로 제작.
- 전설 가호 6종: 왕관·금속 장식과 속성 중심 그림. 상세창 이미지는 170×170 게임 단위로 제한하고 중앙 정렬.
- 하단 메뉴 5종: 입체 로켓·강화 방패·도감 책·카드·톱니바퀴. 선택 상태 금색 테두리, 다른 상태 파란 입체 버튼.
- 카드첩 33장과 이야기 조각: 사용자 최신 요청에 따라 카드첩 내부를 무채색으로 통일. 카드 상세창도 동일하게 표시한다. 가호·전투·하단 메뉴의 색은 유지한다.
- 지역 카드 5장: 일반 이모지·전투 배경 대신 대표 장소를 단순화한 입체 미니어처. 공식 상징 로고 복제나 실측 건축 도면이 아닌 교육용 삽화이다.

## 제작 사양·프롬프트 요약

모든 새 그림은 내장 이미지 생성 도구로 제작했다. PNG 알파 채널을 보존하고 원본 시트는 그대로 둔다. 게임에서 칸을 잘라 투명 여백을 정리하며 정사각형 아이콘 안에 비율을 유지해 배치한다.

- `assets/img/boon_duo_3d_sheet.png`: 5×2, 얼음번개·폭풍 해일·벼락불·천광·수증기 폭발·눈보라·태풍·윤슬·불꽃 회오리·노을불꽃. 채도 높은 에나멜, 금속 경사면, 밝은 하이라이트, 둥근 진한 윤곽선, 글자 없는 투명 배경.
- `assets/img/boon_legend_3d_sheet.png`: 3×2, 천둥 용·빙하·대해일·불꽃 봉황·잎 폭풍·노을 등대. 작은 왕관과 금빛 장식이 결합된 입체 배지, 글자 없는 투명 배경.

- `assets/img/menu_nav_3d_sheet.png`: 가로 5개, 하늘색 로켓·금빛 강화 방패·초록 도감 책·보라 카드·청록 톱니바퀴. 전용 무기 아이콘과 같은 입체 에나멜·금속 스타일.
