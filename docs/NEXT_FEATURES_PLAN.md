## 1. 정화 대폭발
- 이름: **정화 대폭발**(교육용이라 '핵폭탄' 대신). 하얀 빛이 화면 전체로 퍼지며 정화되는 연출.
- 얻는 법: 기지 **강화 탭(상점)**에 '정화 대폭발 300코인'. 가진 개수 최대 **1개**(이미 있으면 구매 버튼 잠김).
- 쓰는 법: 전투 화면 필살기 버튼 위 작은 둥근 버튼(가지고 있을 때만 보임). 누르면 확인 없이 바로 사용, 한 판에 1번.
- 효과: 화면의 적 탄 **전부 지움** + 일반 적(정예 포함) **모두 정화** + 보스 **최대 체력의 10%** 피해 + 1초 무적.
- 쓰지 않고 판이 끝나면 다음 판으로 그대로 남는다(사서 쓰기 전까지 1개 보관).
- 오늘의 도전에서는 **사용 불가**(순위 공정성) — 버튼이 회색으로 보이고 "오늘의 도전에서는 쓸 수 없어요".
- 교사 모드: 무료로 항상 1개.
- 바뀔 곳: `save.items.purge`, `src/ui.js` 상점 줄·HUD 버튼, `src/battle.js` `usePurge()`, 효과 그리기 `combat-vfx.js`.
- 그림(선택): 상점·버튼 아이콘 1개 — "하얀 빛을 내는 둥근 정화 구슬, 둘레에 금색 빛 고리, 가운데 작은 하트" (기존 입체 에나멜 스타일).

## 2. 보스 대사 (패턴 대사 + 탄 위 단어 + 정화 반성 대사)
- 패턴이 바뀔 때 보스 머리 위에 **말풍선** 1.6초(같은 대사 연속 금지). 섬광 줄이기 모드에서도 보임(글자라 안전).
- 그 패턴의 **큰 탄(반지름 11 이상)**에 짧은 단어를 얹는다(예: 피싱 문어 낚싯바늘 '당첨', 무한스크롤러 하트 '좋아요'). 작은 탄에는 글자를 안 넣어 화면이 지저분하지 않게.
- 보스가 정화될 때(지금의 ♥ 연출 동안) **반성 대사** 한 줄 → 정화 카드·퀴즈로 이어짐(배운 점과 연결).
- 데이터는 `data/boss_lines.js` 한 파일: `{ 보스: { 패턴: ['대사', ...], words: [...], sorry: '...' } }`. 15개 시군 확장 때 새 보스도 같은 틀로.

## 3. OX 퀴즈 러시 (코인 미니게임)
- 위치: 기지 **출격 탭**에 '🪙 퀴즈 러시' 버튼(오늘의 도전 아래).
- 방식: **60초** 동안 OX 문제가 연달아 나온다. 지금 있는 퀴즈를 그대로 쓴다(보스 OX 30문제 + 카드 퀴즈 23장 → 확장 후 더 늘어남). 모은 카드의 문제를 먼저, 부족하면 전체에서.
- 보상: 맞히면 **10코인**, 틀리면 0코인 + 정답과 짧은 해설을 1초 보여 줌(배움). 한 판 끝나면 "8문제 정답 · +80코인".
- 제한: **하루 3판**(날짜로 셈). 남은 횟수를 버튼에 표시. 체험관 모드 '다음 학생 준비'를 하면 새 학생은 다시 3판.
- 교사 모드: 횟수 제한 없음, 코인은 저장 안 함(지금 규칙과 같음).
- 바뀔 곳: `src/ui.js` 퀴즈 화면은 지금 정화 퀴즈 화면을 다시 씀, `save.quizRush = { date, count }`, `src/main.js` 버튼 연결.

## 4. 중간 저장 (단계마다 자동)
- 지금: 수호신 제단(지역 클리어) 때만 저장 → 지역 중간에 끄면 그 지역 처음부터.
- 바꿀 것: **웨이브·중간 보스·지역 보스를 끝낼 때마다** 저장(`stageCleared`·보스 정화 카드 뒤). 껐다 켜면 '이어하기'로 **그 단계 처음부터**(체력·레벨·무기·가호·코인·위협도 그대로).
- 수업 시간이 끝나서 판이 멈춘 경우(`reason: 'time'`)에도 저장을 지우지 않아 **다음 시간에 이어서** 할 수 있게.
- 그대로 두는 것: 오늘의 도전은 저장하지 않음(순위 공정성), 교사 모드는 저장하지 않음.
- 저장 크기: 한 판 정보만(수 KB)이라 기기 부담 없음. 이어하기 저장본이 예전 버전이면 지금처럼 자동으로 바꿔 읽는다.
- 바뀔 곳: `src/main.js`에 `saveRun` 부르는 곳 2~3개 추가, `finish`에서 `reason === 'time'`이면 `clearRun` 하지 않기, 일시정지 '기지로' 안내 문구를 "지금 단계 처음부터 이어할 수 있어요"로.
