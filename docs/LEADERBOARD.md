# 오늘의 도전 순위표 · 보안 로그인

현재 설정과 사용법은 [SECURITY.md](SECURITY.md)를 따른다.

- 기존 Google 시트와 학생 기록 보내기 주소를 유지한다.
- 예전 읽기 열쇠와 URL의 key 파라미터로 기록을 읽는 기능은 폐기했다.
- 교사 Google 계정을 서버 Script Properties의 ADMIN_EMAILS에 등록한다.
- 게임 설정 → 교사 로그인 → 관리 화면에서 2분 일회용 코드 발급 → 게임에 붙여넣기.
- 교사 화면의 Google 계정 확인이 실패하면 접근을 거절한다.
- 서버 코드는 tools/leaderboard/Code.gs. 수정 후 기존 배포를 새 버전으로 갱신해야 운영 주소에 반영된다.
- 시트는 공개 공유하지 않는다. 반·번호도 학생 정보이므로 교사 권한 없이 조회할 수 없도록 한다.

고정 비밀번호나 읽기 열쇠를 공개 저장소에 넣지 않는다.

## 학생 계정 (2.12.0 유지)
- 학교·반·번호로 계정을 구분하고 닉네임을 표시한다.
- 학생이 직접 숫자 4자리를 정한다. PIN 원문은 보내지 않고 계정별 SHA-256 해시를 보낸다. 해시는 비밀번호와 같은 수준으로 취급하며 공개하면 안 된다.
- 서버의 계정 탭에서 확인하고 5회 오류 시 10분 잠근다. 4자리 PIN은 간편 수업용이며 중요한 개인정보 인증에는 적합하지 않다.
- 기기 간 코인·진행·카드를 동기화하고 기기별 장부로 사용한 코인이 되살아나지 않게 한다.
- 교사의 학생 비밀번호 초기화는 기존 계정 탭 운영 방식과 별개로 관리한다. 코드에 공통 학생 PIN을 넣지 않는다.
