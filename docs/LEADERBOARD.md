# 오늘의 도전 순위표 + 학생 계정 설치 (선생님용, 10분)

> **2.12.0에서 바뀐 것 — 이미 설치하셨다면 이것만 하세요**
> 1. Apps Script 편집기에서 지금 코드 맨 위의 `READ_KEY = '…'` 줄을 따로 적어 둡니다.
> 2. 코드 전체를 지우고 저장소의 새 `tools/leaderboard/Code.gs`를 붙여 넣은 뒤, 적어 둔 READ_KEY 줄로 다시 바꿉니다. 저장.
> 3. **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**. 웹 앱 주소는 그대로라 게임은 고칠 것이 없습니다.
> 4. 시트에 `계정` 탭이 저절로 생기고, `기록` 탭에는 `학교·닉네임·메인 무기` 칸이 더해집니다.
>
> 학생 계정: 학생이 **학교·학년·반·번호·닉네임·비밀번호(숫자 4자리)**로 들어가면(설정 → 내 계정, 또는 오늘의 도전 처음) 해금·강화·카드·코인이 `계정` 탭에 저장되고, 다른 기기에서 같은 정보로 들어오면 그대로 이어집니다.
> - 계정은 **학교+학년+반+번호**로 구분합니다. 학교 이름은 '홍성초'·'홍성 초등학교'를 같은 학교로 맞춥니다. 닉네임은 바꿀 수 있습니다.
> - 비밀번호는 게임에서 암호화해 보내므로 시트에는 암호(긴 영문·숫자)만 남고, 선생님도 원래 숫자를 볼 수 없습니다.
> - **비밀번호를 잊은 학생**: `계정` 탭에서 그 학생 줄의 `비밀번호(암호)` 칸만 지우세요. 다음에 들어올 때 넣는 숫자가 새 비밀번호가 됩니다(기록은 그대로).
> - 5번 틀리면 10분 잠깁니다(`잠금 끝` 칸). 바로 풀려면 `틀린 횟수`·`잠금 끝` 칸을 지우세요.
> - 학생이 '나가기'를 하면 서버에 저장한 뒤 그 기기의 기록을 비웁니다(같은 패드를 다음 친구가 써도 섞이지 않게).


학생이 오늘의 도전을 마치면 **반·번호와 기록**이 선생님 구글 시트로 자동으로 들어가고,
게임의 교사 모드에서 날짜별 순위표를 볼 수 있습니다. 서버는 필요 없습니다.

## 1. 구글 시트 만들기
1. 구글 드라이브에서 **새 구글 시트**를 만들고 이름을 `충남 수호대 순위표`로 정합니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 원래 있던 내용을 모두 지우고, 저장소의 `tools/leaderboard/Code.gs` 내용을 통째로 붙여 넣습니다.
4. 맨 위 `READ_KEY = '여기에-선생님만-아는-열쇠'`의 따옴표 안을 **선생님만 아는 말**로 바꿉니다. (예: `별빛2026가을`)
5. 저장(디스크 모양)을 누릅니다.

## 2. 웹 앱으로 배포하기
1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형 선택(톱니바퀴) → **웹 앱**을 고릅니다.
3. 설정
   - 설명: `충남 수호대 순위표`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**  ← 학생 기기가 로그인 없이 기록을 보내려면 꼭 필요합니다.
4. **배포**를 누르고, 권한 허용 화면이 나오면 선생님 계정으로 허용합니다.
   ("확인되지 않은 앱" 경고가 나오면 고급 → 이동을 누릅니다. 선생님이 만든 코드라 나오는 안내입니다.)
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> 학교(교육청) 구글 계정에서 '모든 사용자' 선택이 막혀 있으면, 개인 구글 계정으로 같은 과정을 진행하세요.

## 3. 게임에 주소 넣기
- `data/config.js`의 `LEADERBOARD_URL = ''` 따옴표 안에 복사한 URL을 넣고 저장소에 올립니다.
  (Claude에게 URL을 알려 주면 넣고 배포까지 해 줍니다.) 그다음 `sw.js`·`src/ui.js`의 VERSION을 올려야 학생 기기에 반영됩니다.
- 교사 기기에서 교사 모드를 켜고 **설정 → 오늘의 도전 순위표 → 열쇠**에 1-4에서 정한 말을 넣습니다. 이 기기에만 저장됩니다.

## 쓰는 방법
- 학생: 오늘의 도전을 처음 누를 때(또는 설정 → 내 계정) **학교·학년·반·번호·닉네임·비밀번호**로 들어갑니다. 건너뛰면 그날은 기록을 보내지 않습니다.
  체험관 모드의 '다음 학생 준비'를 하면 그 기기에서 나가집니다(서버 기록은 그대로).
- 판이 끝나면 결과 화면에 "(닉네임) 보냈어요 ✓"가 나옵니다. 순위표에는 닉네임과 학교·반·번호가 함께 보입니다.
- 선생님: 교사 모드 → 설정 → **오늘의 도전 순위표 → 보기**. ◀ ▶로 날짜를 옮깁니다.
  순위는 **완주 → 도달 지역 → 단계 → 처치 수** 순서이고, 학생마다 그날 가장 좋은 기록 하나만 보입니다.
  모든 기록은 구글 시트 `기록` 탭에 그대로 쌓입니다.

## 개인정보·보안 메모
- 실명은 받지 않습니다(닉네임에 진짜 이름을 쓰지 않도록 화면에서 안내). 학교·반·번호·닉네임과 암호화한 비밀번호, 게임 진행 기록만 선생님 시트에 저장됩니다.
- 순위를 읽으려면 열쇠가 필요합니다. 다만 기록 보내기는 누구나 할 수 있어서(게임 코드가 공개되어 있으므로),
  장난 기록이 들어오면 시트에서 그 줄을 지우면 됩니다. 시험·평가용 점수로 쓰지는 마세요.
- 시트 코드가 맨 앞의 `= + - @`를 지워서 시트 수식이 실행되지 않게 막습니다.

## 바꾸고 싶을 때
- 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다. URL은 그대로입니다.


### 학년·반 분리 입력 (2.14.1)

계정 화면은 학교, 학년·반·번호, 닉네임, 비밀번호 순서입니다. 예를 들어 학년에는 `5`, 반에는 `2`, 번호에는 `13`을 각각 입력합니다. 반에 `5-2`를 입력하면 오류 안내를 표시합니다.
서버 통신에는 학년과 반을 합친 `cls: '5-2'`를 유지하므로 Apps Script 재배포 없이 같은 계정·비밀번호와 기록을 찾습니다. 기존 로그인 정보도 화면에 학년과 반을 나눠 표시합니다. 계정 식별에 닉네임은 사용하지 않습니다.
