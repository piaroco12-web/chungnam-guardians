## 1. `feature_icons_sheet.png` — 기능 아이콘 4칸 (필수)
- 4열 × 1행, 칸마다 384×384 → 전체 **1536×384**, 투명 배경, 칸 가운데에 하나씩, 가장자리 8% 여백.

| 칸 | 쓰는 곳 | 그림 설명 |
|---|---|---|
| 1 | 정화 대폭발 (상점 줄 · 전투 버튼) | 하얀빛을 내는 둥근 **정화 구슬**, 둘레에 금색 빛 고리 2겹, 가운데 작은 분홍 하트, 구슬 주변에 작은 별 반짝임. 폭탄·버섯구름·불꽃 느낌은 **넣지 않음** |
| 2 | 정화 대폭발 '쓸 수 없음' (오늘의 도전) | 1번과 같은 구슬이 투명한 유리 덮개 안에 들어 있고 작은 자물쇠가 달림 (색은 1번과 같게, 회색 처리는 코드가 함) |
| 3 | OX 퀴즈 러시 (출격 탭 버튼) | 초록 **O 팻말**과 빨간 **X 팻말**이 엇갈려 서 있고, 그 사이에서 금색 코인 3개가 튀어 오름, 작은 모래시계 |
| 4 | 자동 저장 표시 (화면 오른쪽 아래에 잠깐) | 별 모양 장식이 달린 파란 **책갈피**가 펼친 작은 책에 꽂힘, 체크 표시 반짝임 |

## 2. `purge_burst.png` — 정화 대폭발 터지는 순간 (선택)
- 크기 1024×1024, 투명 배경, 가운데에서 바깥으로 퍼지는 모양 하나.
- 설명: 가운데 하얀 빛 구슬에서 **하얀·금색 빛 고리가 둥글게 퍼지고**, 고리 위에 하트·별·작은 꽃잎이 흩날림. 끝으로 갈수록 투명해짐. 폭발 연기·불·파편 **없음**.
- 쓰는 곳: 대폭발을 누르면 1초 동안 크게 커지며 사라짐(없으면 코드로 그린 빛 고리로 대신).

## 3. `quiz_rush_host.png` — 퀴즈 러시 진행자 (선택)
- 크기 768×768, 투명 배경, 상반신.
- 설명: 게임 파일럿 **센터이**(assets/img/pilot_centeri.webp와 같은 캐릭터, 같은 옷·머리)가 한 손에 O 팻말, 한 손에 X 팻말을 들고 활짝 웃으며 퀴즈를 내는 모습. 머리 위에 작은 물음표 말풍선(글자 없이 ? 기호만).
- 쓰는 곳: 퀴즈 러시 화면 위쪽(없으면 지금의 센터이 그림을 씀).

## 4. 보스 대사 말풍선 — 그림 필요 없음
- 말풍선과 탄 위 글자는 코드로 그립니다(글자 크기·길이가 대사마다 달라서 그림보다 코드가 낫습니다). 요청하지 않아도 됩니다.

## 5. 넣는 법 (그림을 받은 뒤 — Claude 또는 GPT)
1. PNG를 `assets/img/`(와 원본은 `art-src/img/`)에 넣고 `python tools/to_webp.py`.
2. `src/assets.js`의 `NAMES`에 `'feature_icons_sheet'`(받은 경우 `'purge_burst'`, `'quiz_rush_host'`도) 추가.
3. 아이콘 칸 순서는 위 표와 같게: 0 정화 대폭발 · 1 쓸 수 없음 · 2 퀴즈 러시 · 3 자동 저장.
4. `sw.js`와 `src/ui.js`의 VERSION을 **같은 번호로** 함께 올리기.

주의: 그림 파일을 넣기 **전에** `NAMES`에 이름부터 넣으면 브라우저 콘솔에 "파일 없음" 오류가 납니다.
