# 2.15.3 무기 진화 해금 카드

카드첩에 일반 진화 10종·궁극 진화 5종·보조무기 진화 5종을 추가한다. 전투 레벨업에서 해당 진화를 실제 선택하면 고유 카드가 저장되고 획득 화면이 열린다. 다시 선택해도 중복 획득하지 않는다. 궁극 진화의 기존 함수 카드도 함께 유지한다.

카드첩에는 범주별 획득 수와 총 84장 진행도를 표시한다. 잠긴 진화 카드를 눌러 효과·조합 조건을 확인할 수 있다. 일반 진화는 청록, 궁극은 금빛, 보조무기는 보라색으로 구분하고 기존 진화 그림과 입체 테두리를 사용한다. 상세 조건 상자는 길이에 따라 스크롤된다.

학습 카드 64장의 기존 캐릭터·칭호·능력치·기체 색 완성 보상은 그대로 유지한다. 진화 카드는 별도 수집 항목이며 기존 cards 목록의 저장·계정 합집합 동기화를 사용한다. 교사 미리보기는 학생 카드 기록을 쓰지 않는다. 과거 전투별 진화 이력은 영구 저장되지 않았으므로 과거 획득을 추정해 소급 지급하지 않는다.

## 검증

추가 검사: 모든 진화의 실제 레벨업 처리·카드 획득과 중복 방지·궁극 함수 카드·게임 조건 일치·학습 보상 보존·재로딩 및 계정 병합·교사 기록 분리.

브라우저 화면 검증은 로컬 서버 연결 거부로 완료하지 못했다. `tools/evolution-cards-preview.html`에서 실제 UI·원화를 메모리 예시로 확인할 수 있다. 이 페이지는 계정 서버 호출이나 persist를 실행하지 않는다.
