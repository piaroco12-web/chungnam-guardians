# 2.15.2 정예 보상 선물상자

정예 처치 후 떨어지는 이모지 선물상자를 신규 투명 원화로 교체한다. 금빛 상자·붉은 매듭·옥빛 잠금장식, 왼쪽 위 광원과 청록 가장자리 빛을 사용한다.

- 게임용 `assets/img/item_gift_2152.webp`: 256px, 약 23KB. 실제 그리기 상자 44 논리 픽셀.
- 이미지 실패 시 금빛 입체 상자와 붉은 리본을 코드로 그린다.
- 천천히 떠오르는 움직임과 작은 반짝임을 쓰고, 섬광 줄이기·저성능 모드에서는 정지 표시한다.
- 정예 출현·획득 반경·레벨업 +1·옆전 +10 규칙은 변경하지 않는다. 피싱 문어의 가짜 선물은 별도 그림을 유지한다.
- 검증: drawRewardChest의 이미지·fallback·섬광 줄이기·좌표 검사를 기존 전체 검사와 함께 실행한다.

생성 도구: 기본 이미지 생성 도구. 주요 프롬프트: 밝은 교육용 슈팅 게임의 단일 정예 보상 스프라이트, 둥근 금빛 상자, 붉은 전통 매듭과 옥빛 보석, 3/4 상단 시점, 두꺼운 외곽선과 셀 셰이딩, 텍스트 없는 투명 배경, 작은 화면에서 읽히는 큰 색면.
