# 위성·주변 발사대·파동포 디자인 2.10.4

인게임에서 위성은 충돌 반경 r=3을 그림 크기로 사용해 지나치게 작았다. 위성 본체를 기본 35~42px, 진화 48px 정도로 분리해 그리며, 궤도·개수·피해·충돌 반경은 유지한다. 기본/진화 위성의 그림을 강화 카드와 보유 칸에도 연결했다.

보조 포탑(단일·쌍포신), 평상시 기체 드론, 필살기 편대 드론, 거대 광선 발사기를 새 입체 그림으로 교체했다. 실제 발사 위치는 동일하다. 거대 광선은 기존 90px 폭 안에서 부드러운 광량과 고리를 표시한다. 단순 사각 빔의 과도한 폭 떨림은 제거했다. 섬광/동작 줄이기에서는 추가 움직임을 줄인다.

파동포는 기본·대형·수호·궁극 4종 물결 이미지를 크기가 고정된 초승달 파동 띠 안에 클리핑해 표시한다. 최근 2.10.3의 고정 크기·전진 이동과 2.10.2의 재사용 시간·피해량을 보존한다. 위협도·해금·퀴즈 등 게임 규칙은 수정하지 않는다.

내장 이미지 생성 도구 제작. 원본은 art-src/img/, 배포 WebP는 assets/img/:
- support_units_sheet (3×2): 기본 위성, 진화 위성, 기본 포탑 / 진화 포탑, 편대 드론, 광선 발사기
- wave_projectile_sheet (2×2): 기본, 대형 / 수호, 서해 해일

유닛 프롬프트: 탑다운, 둥근 남색 외곽선과 은백·금빛 금속 베벨, 코발트/보라 태양전지판, 민트 렌즈·분홍 포신·연두 주황 발사기, 셀 셰이딩·좌상단 광원·투명 배경. 파동 프롬프트: 위로 볼록한 얕은 물결 아치, 하늘·코발트·민트의 입체 물결과 흰 거품, 수호 하트·궁극 금빛 보석, 투명 배경. 실제 생성 시트 경계에 맞춰 런타임에서 독립 크롭한다.
