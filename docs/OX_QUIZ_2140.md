# 2.14.0 · 일일 주제 OX 퀴즈

## 요청과 구현

충남 지역화, AI 윤리·기초와 SW 코딩, 민주시민·생태시민, 학교폭력 예방의 네 주제를 하루마다 순환한다. 각 80문항, 총 320문항이며 각 문항에 정답·해설·공식 근거 식별자를 붙였다.

- 한국 시간 자정 기준. 2026-10-26 지역화, 27일 AI·SW, 28일 시민·생태, 29일 학교폭력 예방, 30일 지역화로 이어진다. 요일 고정이 아닌 4일 순환이다.
- 그날 주제의 80문항 안에서 Fisher–Yates 방식으로 섞는다. 소유 카드·보스·해금 여부로 문제를 제한하지 않는다.
- 한 판에서 문항을 재사용하지 않는다. 답변한 ID를 저장하여 다음 판에는 미출제 문항을 먼저 내고, 모두 경험한 뒤에도 최근 20문항을 뒤로 미룬다. 영원히 반복되지 않는다고 보장하는 방식은 아니며 유한한 문제은행의 반복을 줄이는 방식이다.
- 출제 이력은 로컬·학생 계정 진행 기록에 포함한다. 여러 기기 사이에 이미 푼 ID를 합치되 정확한 전역 출제 시간 순서는 보장하지 않는다. 교사 미리보기는 학생 이력을 바꾸지 않는다. 공용 기기 초기화 시 이력도 지운다.
- 기존 60초, 정답당 10코인, 하루 3판을 유지한다. 시작 시 횟수를 기록하여 중도 새로고침으로 제한을 건너뛰지 않게 했다. 날짜가 바뀌는 중에도 시작한 판의 주제는 고정된다. 기지에서 다시 시작하면 새 날짜를 적용한다.
- 정오답 모두 해설을 보여 주고, 판 종료 뒤 접을 수 있는 문제별 해설·출처 링크를 제공한다. 출처는 새 탭에서 열며 `noopener noreferrer`를 적용했다.
- 보스 정화 퀴즈와 수업 마무리 카드 복습은 기존 내용 연결을 유지한다.

## 근거 확인

첨부된 「2027년 충남교육 주요업무계획 제2차(안)」 HWPX를 kordoc 4.24.6으로 추출하고 원본 XML 텍스트와 관련 항목을 대조했다. 구조·텍스트를 확인했으며 인쇄 화면 전체를 렌더링한 검수는 아니다. 참고 항목은 2-1-1 참여와 자치로 여는 민주시민교육, 2-2-4 공감과 존중의 학교폭력 예방, 2-3-4 생태시민을 기르는 환경교육, 인공지능윤리 교육과정이다. 미확정 사업 규모·예산·예정 날짜를 확정 사실로 출제하지 않았다. 첨부 초안 원문은 저장소에 올리지 않는다.

공개 근거는 충청남도·시군 문화관광/농업 자료, 국가유산청, 충남교육청 생성형 AI 안내서, 교육부 윤리원칙·AI 수행평가 관리·민주시민교육 계획, 국립특수교육원 AI·SW 교육자료, 교육청 환경·학교폭력 예방 자료 등을 사용했다. 전체 문항별 근거는 `data/quiz-bank.js`와 `docs/OX_QUIZ_BANK.md`에 있다. 확인일 2026-10-26.

기관 사이트 일부는 직접 HTTP 확인에서 503 또는 스크립트 전환을 반환했으므로 공식 검색에 수록된 본문과 공식 공개 문서의 내용을 함께 확인했다. 모든 기관 링크가 모든 접속 환경에서 항상 열린다는 뜻은 아니다. 확인 중 404를 반환한 서천군 옛 안내 링크는 충청남도 신성리 갈대밭 공식 상세 페이지로 교체했다. 외부 사이트 장애가 있어도 게임 내 문제와 해설은 오프라인 사용 가능하다.

문항과 생활 사례는 새로 작성했다. 근거 문서의 문장·사진·삽화·표를 복제하거나 공공누리 변경금지 문서를 개작해 배포하지 않는다. 링크와 자료명은 사실 확인 경로다.

- `src/ui.js`와 `sw.js` VERSION은 모두 2.14.0. 새 모듈 `src/daily-quiz.js`, `data/quiz-bank.js`를 오프라인 CORE 목록에 추가했다.
