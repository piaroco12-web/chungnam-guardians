# 무기·지역 몬스터 그림 2.10.1

첨부 WEAPON_IMAGES_FOR_GPT.md 순서에 맞춰 메인 5종, 진화 A/B/궁극 15종, 지뢰·포탑과 진화 4종을 제작했다. 선택·강화 카드·일시정지·보유 무기 칸에 실제 그림을 연결했다. 진화한 서브 무기의 칸도 전용 그림을 사용한다.

지역 몬스터 6종(좋아요 벌, 복붙 슬라임, 뒷담 나방, 낚시 물고기, 매연 드론, 편향 눈알)은 전용 3×2 시트를 먼저 사용한다. 기존 지역 색상 변형, 정예 표시와 이동·공격 패턴을 보존한다.

원본 PNG는 `art-src/img/`, 투명 WebP는 `assets/img/`의 다음 파일이다.
- weapon_main_sheet: 5×1
- weapon_evo_sheet: 5×3, 행 A/B/궁극
- weapon_sub_sheet: 4×1, 지뢰/포탑/연쇄 지뢰/쌍둥이 포탑
- enemy_region_sheet: 3×2, 벌/슬라임/나방/물고기/드론/눈알

내장 이미지 생성 도구 사용. 무기 프롬프트는 지시서 표의 소재와 순서를 그대로 적용하고, 남색 외곽선(#17123a), 금·보라·하늘·민트·물빛 에나멜, 금속 베벨, 좌상단 광원과 셀 셰이딩으로 통일했다. 몬스터는 둥근 미니어처와 귀여운 표정, 실제 투명 배경으로 제작했다. 생성본 실제 크기에 맞춰 assets.js에서 칸별 크롭과 투명 여백을 정리한다.

전투 시각: 진화 단계 메타데이터만 탄에 더했다. 기관포 별빛·정밀·은하, 산탄 폭죽·근접·궁극, 플라스마·전기 레일·오로라, 입체 민트 유도 미사일·추적 점선·별똥별, 수호 회복 표시·해일 물결을 구분한다. 지뢰와 포탑은 베벨 링과 렌즈를 더했다. 총구 연출은 발사 직후 짧게 표시하고 섬광/동작 줄이기에서는 생략한다. 피해량, 탄 수·속도, 충돌 반경, 해금 조건은 바꾸지 않았다.

검증: `reports/armory-2101-verification.json`: 아이콘 24개, 지역/정예 조합 60개, 실제 무기 발사·렌더 20조합, 1120·540·390·320 너비, 진화 서브 무기 보유 칸. `tools/verify_release.py`의 출격·정화·퀴즈·카드·제단·음원 디코딩·오프라인·터치 검증도 통과했다.

미리보기: `tools/armory-preview.html` (실제 게임 그림과 전투 함수를 사용하며 진행 기록을 저장하지 않는다).
