# 메인 무기 선택 구조 (2026-10-25 사용자와 질문으로 결정, 구현 전 설계)

| 항목 | 결정 |
|---|---|
| 고르는 시점 | 출격 전 따로 선택: 파일럿 → 기체 → **메인 무기** → 난이도 |
| 무기 수 | 5종: 기관포 · 레이저 · 산탄 · 유도탄 · 파동포 |
| 선택 효과 | 기본 수치 장단점 + 짝 강화 보너스 + 레벨업 선택지 비중 + 무기별 진화 모습 (넷 다) |
| 조합 구조 | 무기마다 짝 강화 2개 → 진화 2갈래. 한 판에 하나만 받고, 짝 2개를 모두 Lv.5로 채우면 **궁극 진화** |
| 해금 | 기관포·산탄은 처음부터. 나머지 3종은 **무기 사슬**(숙련도) |
| 서브 무기 | 겹치는 산탄포·유도 미사일 → **지뢰 투하 · 보조 레이저 포탑**으로 교체 |
| 짝 강화 등장 비중 | 레벨업 선택지에서 **1.5배** |
| 기체 역할 | 필살기 + 능력치 배율 + **궁합 무기 1~2종**(맞으면 피해 +10%) |
| 선택 화면 | 능력 막대(피해·연사·관통·사거리·쉬움) + 짝 강화·진화 미리보기 + 궁합 ★ |

## 1. 메인 무기 5종 (제안 수치, 구현 후 봇으로 조정)
| id | 이름 | 성격 | 연사(발/초) | 1발 피해 | 관통 | 특징 | 쉬움 |
|---|---|---|---|---|---|---|---|
| gun | 기관포 | 속사 | 8 | 10 | 0 | 곧게 빠른 탄 | ★★★★★ |
| spread | 산탄 | 근거리 | 2.2 (5발) | 9 | 0 | 부채꼴, 사거리 짧음(0.45초 뒤 사라짐) | ★★★★ |
| laser | 레이저 | 관통 | 3 | 24 | 모두 | 느리지만 줄 전체를 꿰뚫음 | ★★★ |
| homing | 유도탄 | 자동 조준 | 3 (2발) | 14 | 0 | 가까운 적을 따라감 | ★★★★★ |
| wave | 파동포 | 생존 | 0.7 | 68 | 모두 | 앞쪽 60° 고리 파동(2.10.2 조정), 닿은 적 탄을 지우고 적을 밀어냄 | ★★★ |

- 레벨업의 **메인 무기 강화**(지금의 '기본 무기 강화', `weapons.main`)는 고른 무기 이름으로 보인다. Lv마다 피해 +20%.
- 파일럿 충남이의 '+1발'은 무기에 맞게: 기관포·유도탄 +1발, 산탄 +1갈래, 레이저 +1줄, 파동포 폭 +20°.

## 2. 짝 강화와 진화 (사용자 확정)
| 무기 | 짝 강화 A → 진화 A | 짝 강화 B → 진화 B | 궁극 (A·B 짝 모두 Lv.5) |
|---|---|---|---|
| 기관포 | 연사 → 별빛 폭풍 (3갈래) | 치명타 → 저격 연사 (치명타 3배) | 은하 기관포 |
| 레이저 | 탄 크기 → 플라스마 창 (굵기 2배) | 탄속 → 레일건 (즉발 2줄) | 오로라 광선 |
| 산탄 | 피해 범위 → 폭죽 산탄 (맞으면 폭발) | 공격력 → 근접 포화 (가까울수록 강함) | 불꽃놀이 산탄 |
| 유도탄 | 빠른 충전 → 군집 유도 (발 수 2배) | 지속 시간 → 끈질긴 추적 (관통 후 재추적) | 별똥별 유도 |
| 파동포 | 피해 범위 → 대형 파동 | 최대 체력 → 수호 파동 (탄 지우면 회복) | 서해 해일포 |

규칙
- 진화 조건: 메인 무기 Lv.5 + 짝 강화 Lv.1 이상 → 그 진화가 레벨업 선택지에 나온다. 둘 다 조건이면 둘 다 보이고 **하나만** 고른다.
- 궁극: 진화를 하나 받은 뒤 짝 강화 A·B를 **모두 Lv.5** → 궁극 진화가 선택지에 나온다(받은 진화를 대체·강화).
- 짝 강화 보너스: 고른 무기의 짝 강화는 효과 +25% (예: 기관포에서 연사 Lv.1 = +8% → +10%).
- 지금의 기체별 진화 `evo_main`(별빛 폭풍/드론 군단/플라스마 창)은 이 표로 옮겨 없앤다. 드론 군단은 드론호 기체 특성으로 남긴다(드론 +2대는 필살기 쪽에서 검토).

## 3. 기체 역할
| 기체 | 능력치 배율 | 궁합 무기 (피해 +10%, 선택 화면 ★) | 필살기 |
|---|---|---|---|
| 별빛호 | 연사 ×1.1 | 기관포 · 산탄 | 별빛 파동 (그대로) |
| 드론호 | 피해 ×0.9, 드론 2대 | 유도탄 · 파동포 | 드론 편대 (그대로) |
| 번개호 | 피해 ×1.15, 연사 ×0.85 | 레이저 | 거대 광선 (그대로) |

## 4. 해금 — 무기 사슬 (숙련도 = 그 무기를 메인으로 들고 정화한 일반 적 수, 기기에 누적)
- 기관포 500마리 → **레이저**
- 산탄 500마리 → **유도탄**
- 레이저 500마리 **그리고** 유도탄 500마리 → **파동포**
- 교사 모드는 모두 열림. 잠긴 무기 카드에 "기관포로 312/500" 진행 표시.
- 결정: 번개호를 이미 연 학생도 레이저는 따로 열어야 한다(자동으로 열지 않음). — 2.10.0 구현 완료

## 5. 서브 무기 교체

|---|---|---|---|
| 산탄포 | 지뢰 투하: 지나간 자리에 지뢰, 닿으면 폭발 (옆·뒤에서 오는 적 대비) | 탄 크기 | 연쇄 지뢰 |
| 유도 미사일 | 보조 레이저 포탑: 양옆 포탑이 가까운 적을 자동 조준 | 빠른 충전 | 쌍둥이 포탑 |

## 6. 바뀔 파일 (구현 순서)
1. `data/weapons.js` 새로 만들기: `MAIN_WEAPONS`(수치·짝·진화·궁극·궁합·해금 조건)와 `SHIP_AFFINITY`. 숫자는 여기에서만 바꾼다.
2. `data/build.js`: 서브 무기 교체, `evo_main` 제거, 진화 목록을 메인 무기 표에서 만들어 붙이기.
3. `src/progress.js` `levelChoices()`: 짝 강화 비중 1.5배, 진화 A/B 둘 중 하나, 궁극 조건.
4. `src/battle.js` `playerFire()`: `this.ship.fire` 대신 `run.mainWeapon`의 발사 방식(5종) + 기체 배율·궁합. 지뢰·포탑 서브 무기.
5. `src/save.js`: `mastery: { gun, spread, laser, homing, wave }`, `weaponUnlocked()`·`weaponProgress()`. 처치 때 메인 무기 숙련도 +1.
6. `src/ui.js`: 출격 단계 '메인 무기' 화면(능력 막대·짝·진화·궁합 ★·잠금 진행), 레벨업·일시정지 화면의 무기 이름.
7. `newRun({ mainWeapon })`, 오늘의 도전은 날짜로 무기도 정함(열린 무기 중), 이어하기 저장본에 `mainWeapon`이 없으면 기체 원래 무기로.
8. `tools/sim.js` 봇이 무기도 고르게 → 무기별 승률·시간 비교 후 수치 조정.
9. 그림: 무기 5종 아이콘, 진화 15종 아이콘, 새 서브 2종 → GPT 프롬프트 (`docs/NEXT_TODO.md`).
