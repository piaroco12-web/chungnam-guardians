# 선택 화면 디자인·모션 2.5.2

- 갈림길 5종을 전용 입체 그림으로 교체: 코인 보물, 치유 분수, 수련 제단, 가호 제단, 정예 수호자. 응급 수리 보너스도 실제 도구 그림을 사용한다.
- 업그레이드·수호신 제단·12지신 동료 선택창에 입체 카드 표면과 선명한 제목판·그림 메달을 적용했다. 파일럿·기체·난이도 선택과 카드 획득 확인도 같은 확정 피드백을 사용한다.
- 등장 340ms, 확정 330ms. 선택한 카드 확대, 나머지 카드 후퇴, 짧은 빛 스윕·8개 반짝임·선택 완료 표시를 사용한다. 영상 파일을 내려받는 대신 브라우저 기본 애니메이션으로 표시한다.
- 확정음은 기존 CC0 카드 선택 음원과 작은 합성 차임을 사용한다. 종류별 음 높이를 다르게 하고, main.js에서 중복 재생하던 소리는 제거했다. 새로운 외부 음원은 추가하지 않았다.
- 선택 화면당 한 번만 확정한다. 화면 교체 시 이전 지연 콜백을 버린다. 모션은 공격 수치나 난수 생성에 관여하지 않는다.
- 기기의 `prefers-reduced-motion` 또는 게임의 섬광 줄이기 설정에서는 확대·빛·입자 효과를 생략하고 즉시 확정한다. 효과음 끄기도 따른다.
- 최신 카드첩 디자인과 파일럿 탑승, 가호 전투 효과는 유지한다.

## 그림 제작

내장 이미지 생성 도구로 `art-src/img/choice_routes_sheet.png`를 생성했다. 요청 사양: 3×2 투명 시트, 각 칸에 하나의 입체 미니어처, 둥근 진한 외곽선·채도 높은 에나멜 색·금속 경사면·밝은 하이라이트. 순서: 코인 보물상자, 하트 치유 분수, 책·경험치 수정 수련 제단, 6속성 가호 제단, 둥근 정예 딱정벌레와 보물상자, 수리 도구와 하트 코어. `tools/to_webp.py`로 WebP 배포본을 생성했다.
