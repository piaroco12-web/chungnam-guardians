# 충남 15개 시군 확장 — 그림 생성 요청서 (ChatGPT용)

계획서: `docs/EXPANSION_15_PLAN.md`. 이 문서의 프롬프트를 **한 항목씩** 복사해서 쓰면 됩니다.
받은 PNG는 원본을 `art-src/img/`에, 같은 파일을 `assets/img/`에 넣고 `python tools/to_webp.py`를 실행합니다.
그 뒤 코드 연결(이름 등록·VERSION 올리기)은 Claude가 합니다.

## 0. 모든 그림 공통 스타일 (매 프롬프트 앞에 붙이기)

```
[공통 스타일] 초등학생용 교육 슈팅 게임 '충남 수호대' 그림. 기존 그림(assets/img의 boss_*.webp, enemy_sheet.webp, bg_*.webp)과 같은 스타일:
밝고 선명한 입체 미니어처, 에나멜 광택, 부드러운 그림자, 둥글고 굵은 진한 남색 외곽선(#17123a 계열), 위 왼쪽에서 오는 빛.
귀엽지만 장난스럽게 못된 표정(무섭거나 잔인하지 않게). 글자·숫자·로고·실제 상표 없음. 실제 사진을 베끼지 말고 단순화한 교육용 삽화.
```

정화(cleansed) 그림 공통: **같은 캐릭터**가 착한 모습으로 바뀐 버전. 표정이 밝고, 색이 파스텔로 부드러워지고, 주변에 하트·반짝임. 크기·구도·시점은 기본 그림과 똑같이.
