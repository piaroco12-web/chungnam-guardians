## 1. 해금한 카드는 색깔로 보이게

현재: GPT 2.3.2에서 카드첩 전체를 흑백으로 바꿈.
- `style.css:130` — `.card-collection,.monochrome-card{filter:grayscale(1)}` (카드첩 전체·카드 상세창이 흑백)
- `src/ui.js:177` — `cardModal()`이 `monochrome-card` 클래스를 씀

할 일
1. 흑백은 **아직 못 얻은 카드**(`.ccard:not(.got)`)에만. 얻은 카드(`.ccard.got`)와 카드 상세창(`cardModal`)은 색깔.
   - `style.css:130`을 `.card-collection .ccard:not(.got){filter:grayscale(1)}`로 바꾸고, `cardModal`에서 `monochrome-card` 클래스를 뺀다.
   - 이야기 조각도 열린 것은 색깔, 잠긴 것은 흑백으로 맞춘다.
2. **지역 카드 5장 그림은 그림 자체가 흑백**(`assets/img/region_landmarks_sheet.webp`, 원본 `art-src/img/region_landmarks_sheet.png`).
   CSS로는 색이 돌아오지 않으므로 색 그림이 필요하다 → 아래 GPT 프롬프트로 받는다. 받기 전까지 지역 카드는 지금 그림 유지.
3. 확인: 카드첩(얻은/못 얻은), 카드 상세창, 카드 획득 화면, 교사 모드(전부 열림) 화면 캡처.

### GPT 프롬프트 (지역 상징 그림 컬러판)
```
게임 '충남 수호대'의 지역 카드 그림 5장을 컬러로 다시 만들어 줘. 지금 흑백 입체 미니어처(art-src/img/region_landmarks_sheet.png)와
구도·크기·배치(3×2, 마지막 칸 비움)를 그대로 두고 색만 입힌 느낌으로.
1) 아산: 현충사 기와 건물과 온천 김  2) 공주: 공산성 금서루와 성벽  3) 부여: 정림사지 오층석탑과 연못
4) 보령: 대천해수욕장 모래사장과 갯벌 머드  5) 내포: 충남도청 청사와 광장
스타일: 메뉴 아이콘과 같은 밝은 입체 미니어처(에나멜 광택, 부드러운 그림자, 둥근 진한 남색 외곽선), 투명 배경, 글자·로고 없음.
파일: region_landmarks_sheet.png, 전체 가로 약 2000px. 실제 사진을 베끼지 말고 단순화한 교육용 삽화로.
```
받으면: PNG를 `assets/img/`에 넣고 `python tools/to_webp.py` → VERSION 올리기.

## 2. 몬스터 체력 늘리기

사용자 지정 배율: **일반 몬스터 ×2, 중간 보스 ×2, 지역 보스 ×3, 최종 보스 ×4**

고칠 곳
- 일반 몬스터: `src/battle.js:143` — `const hp = d.hp * this.scaleHp();`
- 보스: `src/battle.js:155` — `const hp = b.hp * this.diff.hp * (1 + this.run.region * 0.35) * …`
- 최종 보스 = 내포 지역 보스 `aicore`(폭주 AI 코어). 지역 보스 = scroller·deepfaker·thorn·octopus. 중간 보스 = blackhole·copybot·cloud·slot·smog.

방법: 숫자를 데이터에 흩지 말고 배율 한 곳에 둔다.
```js
// data/content.js
export const HP_MULT = { enemy: 2, mid: 2, boss: 3, final: 4 };
// battle.js:143  → d.hp * HP_MULT.enemy * this.scaleHp()
// battle.js:155  → b.hp * (isMid ? HP_MULT.mid : id === 'aicore' ? HP_MULT.final : HP_MULT.boss) * …
```

주의 (밸런스)
- 보스 체력에는 이미 지역 배율 `(1 + 지역번호 × 0.35)`가 붙는다. 최종 보스는 지금도 기본 5600 × 2.4 = 13,440이고, ×4면 **53,760**(새싹 ×0.7 → 약 37,600)이 된다.
- 지금 자동 조종 기준 한 판이 9~15분이다. 체력을 늘리면 20분 이상으로 길어질 수 있다(수업 시간 모드 10~30분과 맞물림).
- 적용 후 `python tools/balance.py 3`으로 난이도·기체별 도달 지역과 시간을 재고, 기준을 벗어나면 플레이어 쪽(경험치·공격력 성장)을 조금 올려 맞춘다.
  - 기준 제안: 새싹 승률 80% 이상, 도전 50% 안팎, 전설 20% 안팎, 한 판 평균 20분 이내.

## 3. 난이도: 운의 요소 넣기

요청: 몬스터 체력 말고도 운의 요소(선택 실패, 강화 실패 등). 확률은 Claude가 정함.

**주의할 점**: 이 게임은 '사이버도박'(잭팟 슬롯킹) 예방을 가르친다. 돈·코인을 걸고 잃는 '강화 실패'는 확률형 강화(뽑기)와 같은 구조라 메시지와 부딪힌다.
그래서 아래 원칙으로 넣는다.
- 확률은 **화면에 항상 공개**한다 (가호 도감의 등급 확률 표시와 같은 방식).
- 실패해도 **이미 가진 것을 잃지 않는다**. 실패는 '이번 보너스 없음'까지만.
- 위험한 선택은 **학생이 고를 때만** 생긴다(안 골라도 되는 선택지).
- 모든 확률은 한 파일(`data/luck.js`)에 모아 숫자만 바꾸면 조절되게 한다.

넣을 운 요소 (제안 확률)
| 요소 | 내용 | 확률 |
|---|---|---|
| 도전 강화 (레벨업) | 레벨업 카드 중 하나가 가끔 '도전 강화'로 나온다. 고르면 성공 시 2단계 상승, 실패 시 이번 레벨업 효과 없음 | 등장 25% · 성공 65% |
| 흔들리는 제단 (수호신 제단) | 제단 선택지 하나가 뒷면(내용 숨김)으로 나온다. 고르면 영웅 등급 확률 2배 대신 무엇이 나올지 모름 | 등장 20% |
| 보스 패턴 무작위 | 지금은 보스 패턴이 정해진 순서로 돈다(`battle.js:798`). 다음 패턴을 무작위로, 같은 패턴 연속은 피함 | 항상 |
| 보스 분노 | 보스 체력 50% 이하가 되면 확률로 분노(패턴 속도 +20%) | 35% |
| 돌발 웨이브 | 웨이브 시작 때 확률로 이벤트: 유성우(적 탄 +), 정예 1마리 추가, 보급 상자 | 20% (셋 중 하나) |
| 갈림길 결과 변동 | 코인 길 2.5배 고정 → 1.5~3.5배 무작위, 쉼터 길 35% → 25~45% | 항상 |

화면 문구 예: "도전 강화 — 성공 65%: 2단계 상승 / 실패: 이번엔 효과 없음"
수업 연결: 결과 화면에 "이번 판 도전 강화 3번 중 2번 성공(확률 65%)"처럼 기록 → 확률 수업 소재.

고칠 곳: `src/progress.js` `levelChoices()`(9행)·`altarChoices()`(76행)·`rollRarity()`(47행), `src/battle.js` 보스 패턴 전환(798행)·웨이브 시작(`startStage`, 84행), `data/extras.js` PATHS, `src/ui.js` 레벨업·제단 카드 그리기.
확인: `tools/balance.py`(2번과 함께), 확률 표시가 모든 화면에 보이는지, 섬광 줄이기·교사 모드에서 이상 없는지.
