# 디자인 기본 기준

사용자 지시(2026-10-28): 앞으로 모든 디자인은 색감·입체감·디자인 구성을 함께 고려해 제작하고 적용한다.

- 색감: 화면마다 배경·표면·강조·본문의 역할을 정하고, 게임의 청록·금빛 계열과 활동별 보조색을 조화롭게 사용한다.
- 입체감: 기존 일러스트와 일관된 하이라이트·광원·그림자로 버튼과 카드의 깊이, 눌림 상태를 표현한다.
- 구성: 정보 위계, 여백, 한글 줄간격, 터치 영역, 좁은 화면의 잘림 여부를 실제 렌더로 확인한다. 굵은 외곽선이나 장식을 늘려 가독성을 해치지 않는다.
- UI·문서·그림 등 이후 디자인 변경에도 적용한다. 기능과 계정·기록은 보존한다.

## 지도 구분

- 학급 수호 기지: 학급 공동 정화 성과로 15시군 지도 색을 복원한다.
- 메뉴 충남 지도 길: 5권역을 모두 클리어하면 같은 그림 지도를 펼치되, 개인이 직접 클리어한 시군만 활성화한다. 우리 고장 선택·카드 보유·학급 기여만으로 활성화하지 않는다.
- 구버전은 지역별 고유 보스 정화 기록으로 확인 가능한 곳만 복원한다. 홍성·예산의 공유 보스 기록만 있으면 두 도시를 함께 활성화하지 않는다. 새 클리어는 시군 ID를 직접 기록하고 기존 계정 동기화로 보존한다.
