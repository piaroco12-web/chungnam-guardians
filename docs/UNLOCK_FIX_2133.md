# 2.13.3 해금 조건 수정

현재 해금 조건만 사용한다. 구버전 보호 예외는 제거하며 기존 카드·코인·숙련도·정화 기록은 유지한다.

- 센터이: SW·AI 개념 카드 12장 전부.
- 에듀이: 지역 상식 카드 10장. 안내는 “지역 상식 카드 10장을 모으면 열려요”.
- 드론호: 서로 다른 중간 보스 5종 정화.
- 번개호: 에듀이 + 드론호 조합으로 폭주 AI 코어 정화.
- 수집 보상: 지역 상식 15장, SW·AI 개념 12장, 예방 수칙 25장, AI 활용 12장, 전체 64장. 실제 카드 목록으로 판정한다.

## 원인과 변경

기존 규칙 3의 `unlockRule !== 3` 조건이 규칙 4 기록에서도 다시 실행되어 규칙을 낮추고, 규칙 4의 구버전 보호 처리를 매번 재실행했다. 그 결과 이전 카드 6장으로 센터이가 열리는 등 조기 해금이 발생했다.

구버전 이관 처리를 제거했다. 현재 규칙 번호는 `data/unlocks.js`의 `CURRENT_UNLOCK_RULE = 5`로 통일했다. 로컬 기록의 `grandPilots`, `grandShips`, `grandSets`는 삭제하며 해금 판정에서도 사용하지 않는다. 클라우드 기록 병합·업로드에서도 해당 예외 배열을 제외한다. 잘못 열린 해금과 보상은 실제 조건에 따라 다시 판정한다.

파일럿 잠금 안내는 `PILOT_UNLOCK` 설정을 직접 사용한다. `src/ui.js`와 `sw.js`의 버전을 함께 2.13.3으로 올렸다.

## 검증

`node --test tools/unlock-regression.test.mjs` — 14개 통과.

신규 기록, 6장 조기 해금, 11/12장·9/10장 경계, 지역 10장과 수집 보상 15장 구분, 구버전 보상 예외 차단, 전체 64장 보상, 번개호 조합 조건, 중간 보스 중복 제외, 반복 새로고침, 클라우드 예외 차단, 정상 해금 유지, 교사 미리보기 분리를 검증한다.

테스트는 가상 저장소와 실제 게임 모듈을 사용한다. 실제 학생 계정·서버 기록은 수정하지 않는다. 인증·보안 설정은 이번 변경 범위에 포함하지 않는다.
