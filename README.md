## 2.15.4 수집 완성 보상 · 학급 목표 줄이기

## 2.14.6 옆전 · 아이템 시인성

- 코인은 네모 구멍·둥근 금속 테두리·금빛 음영이 있는 옆전으로 통일한다. 전투 수집 아이템, 전투 HUD, 기지 보유액, 강화 구매 버튼 모두 같은 벡터 원본을 사용한다.
- 전투 코인·경험치 그림은 26 → 39 논리 픽셀(1.5배). 메뉴 보유액 34 → 51, 전투 HUD 18 → 27, 강화 가격 26 → 39로 아이콘 크기를 확대한다. 금액·드롭률·획득 반경·경험치 수치는 유지한다.
- 옆전은 코드에 포함한 벡터를 한 번 래스터화해 재사용하며, 오프라인 코드 캐시에 함께 저장된다. 추가 외부 파일이나 다운로드가 필요 없다. `sw.js`·`src/ui.js` 버전 2.14.6 동시 갱신.

## 학급 협동 합의 기록 (2.14.6 당시)

- 평소 각자 참여해 우리 반 성과를 모으고, 행사에는 여러 반이 함께 출격해 공동 목표를 달성한다. 종합 순위 대신 반마다 기여한 활동 기록을 남긴다.
- 전투·퀴즈·탐험에 각각 하루 1칸, 합계 최대 3칸 기여한다. 결석 불이익·연속 출석 보상·미참여 학생 공개는 두지 않는다.
- 모든 학생은 일반 전투와 오늘의 도전을 합쳐 한국 시간 기준 하루 3회 출격한다. 출격 시 차감하고 중단·패배도 포함한다. 이어하기는 추가 차감하지 않고 원래 출격일에 귀속한다. 미사용 횟수 이월은 없다. 교사가 정한 수업 종료 시간도 함께 적용한다.
- 도감·카드첩·지역 이야기는 계속 열람할 수 있다. 학급 규모를 고려해 목표를 설계한다.
- 수업 한 번에도 작은 기지 변화가 생기고, 성과가 쌓이면 충남 지역을 되살린다. 되살린 지역의 장식이 우리 반 기지에 남는다.
- 위 협동·출격 제한은 합의한 기획이며 이번 아이콘 변경에서 구현한 기능이 아니다. 계정·서버 집계와 제한 검증은 후속 구현이 필요하다.

## 2.14.5 유도탄 근접 명중 수정

- 유도탄·드론탄은 적 충돌 반경에서 10 논리 픽셀 이내로 접근하거나 프레임 사이에 스쳐 지나가면 명중 이펙트와 기존 피해를 적용한다.
- 모든 유도탄이 이미 맞힌 적을 추적 대상에서 제외한다. 관통·궁극 진화는 다음 적을 추적하고, 이미 명중한 뒤 새 목표가 없으면 제거해 적 옆에 멈추는 현상을 막는다.
- 공격력·관통 횟수·궁극의 범위 피해는 유지하며 같은 탄의 직접 피해는 적마다 한 번만 적용한다. 공간 격자 검색에도 근접 반경과 이동 경로를 반영한다.
- `sw.js`·`src/ui.js` 버전 2.14.5 동시 갱신.

## 2.14.4 백그라운드 소리 차단

- 다른 탭·앱·창으로 이동하거나 화면 잠금·페이지 숨김이 발생하면 BGM을 즉시 음소거·일시정지하고 Web Audio 출력을 차단한 뒤 처리도 중단한다.
- 재생 중인 효과음과 예약된 합성음을 정지하고, 숨겨진 동안 새 소리를 만들거나 AudioContext를 다시 켜지 않는다.
- 돌아오면 현재 배경음의 위치를 이어 재생한다. 이미 끝난 승리·패배 징글은 반복하지 않으며 사용자가 꺼 둔 음악·효과음 설정은 유지한다. 브라우저가 자동 재생을 막으면 다음 게임 화면 터치·계속하기·키 입력에서 다시 시도한다.
- `sw.js`와 `src/ui.js` 버전 2.14.4 동시 갱신. 기존 전투의 자동 일시정지 동작은 유지한다.

## 2.14.3 보스 주제 탄환

- 보스 25종의 로켓 몸체·날개·추진 불꽃을 없애고, 기존 안쪽 주제 문양 자체를 입체 탄환으로 표시한다. 예: 무한스크롤러 재생 버튼, 대필봇 종이, 피싱 문어 링크 고리.

## 2.14.2 모바일 전투 성능

- 플레이어 탄환 그림·빛 번짐을 최대 64장(픽셀 데이터 약 6MiB) 캐시에 재사용. 종류·강화 단계·진화 갈래·속성은 구분하며 늦게 로드한 미사일 그림도 반영한다.
- 느린 프레임이 약 1.2초 누적되면 장식 반짝임·파편을 줄인다. 안정적인 프레임이 8초 이어지면 복구하며, 일시정지·백그라운드 시간은 제외한다. 적 탄환·위험 영역·공격력·발사 수는 줄이지 않는다.
- 유도탄 목표 검색을 0.08초 간격으로 재사용(조향은 매 프레임). 목표 정화·관통 후 재추적·사거리 이탈 때 즉시 다시 찾는다.
- 플레이어 탄의 충돌 후보를 공간 격자로 좁힌 뒤 기존 판정을 적용. 큰 보스·화면 밖 좌표·넉백·분열도 처리한다.
- `sw.js`와 `src/ui.js` 버전 동시 갱신, 새 모듈 오프라인 사전 저장. 검증: `node --test tools/*.test.mjs`, `node tools/performance-compare.mjs`.

## 2.12.0 학생 계정 (어느 기기에서나 같은 기록)

- 설정 → **내 계정**(또는 오늘의 도전 처음)에서 학교·반·번호·닉네임·비밀번호(숫자 4자리)로 들어간다. 처음이면 계정이 만들어진다.
- 계정 = 학교+반+번호. 학교 이름은 '홍성 초등학교'·'홍성초'를 같은 학교로 맞춘다. 비밀번호는 기기에서 SHA-256으로 암호화해 보낸다.
- 서버는 순위표와 같은 구글 시트(`계정` 탭). 기지에 들어올 때(1분에 한 번)·판이 끝날 때 자동 동기화.
- 합치는 규칙: 카드·해금·도감은 합집합, 강화 단계·통계·숙련도는 큰 값, 코인·정화 대폭발은 기기별 장부(번 것·쓴 것)를 합쳐 계산 → 쓴 코인이 되살아나지 않는다.
- 나가기: 서버에 저장한 뒤 그 기기의 기록을 비운다(공용 패드에서 기록이 섞이지 않게). 저장 실패 시 나가지 않는다.
- 오늘의 도전 기록에 학교·닉네임·메인 무기가 더해지고, 교사 순위표는 학교·반·번호로 학생을 구분한다.
- **선생님 할 일**: 새 `tools/leaderboard/Code.gs`로 바꾸고 새 버전으로 다시 배포(`docs/LEADERBOARD.md` 맨 위).

- **이로치**: 같은 몬스터도 지역마다 색이 다르다. 처음 나오는 지역이 원래 색이고, 다른 지역에서는 `REGIONS[].hue` 차이만큼 색상을 돌린다.
- **피싱 문어** 패턴 3→5개: 소용돌이 사슬(방향 교대) · 바닥에서 솟는 문어 다리 · 아래·옆 가장자리에서 날아오는 낚싯바늘 · 가짜 선물 · 먹물(+아래 모서리 물줄기).
  뒤쪽 공격은 항상 경고(! 표시, 바닥 물결)가 먼저 뜬다. 새싹은 한 곳만.

## 2.7.2 패드에 옛 버전이 남지 않게

- 인터넷이 되면 항상 서버의 새 파일을 먼저 쓰고(바뀌지 않은 파일은 작은 확인만), 4초 안에 안 오면 저장본으로 연다. 오프라인에서도 열린다.
- 새 버전 설치는 코드 파일만 받으면 끝나서 빠르고, 파일 하나가 실패해도 설치가 막히지 않는다. 그림·음악은 뒤에서 조금씩 저장한다.
- 게임을 열 때 서버 버전을 확인해서 다르면 바로 받고, 메뉴 화면이면 저절로 새로고침한다.
- 설정 → **최신 버전 받기**: 저장본을 지우고 새로 받는다(기록은 그대로).
- GitHub Pages 반영에 1~10분이 걸릴 수 있다.

## 2.7.0 오늘의 도전 지역·순위표

- **출발 지역**: 오늘의 도전은 날짜로 정해진 지역에서 출발한다(같은 날이면 누구나 같은 지역). 파일럿·기체도 날짜로 정해진다.
- **순위표**: 학생이 반·번호를 한 번 넣으면 판이 끝날 때 기록이 선생님 구글 시트로 자동 전송되고, 교사 모드 → 설정 → 오늘의 도전 순위표에서 날짜별로 본다.
  설치는 `docs/LEADERBOARD.md`, 시트 코드는 `tools/leaderboard/Code.gs`, 주소는 `data/config.js`. 주소가 비어 있으면 이 기능은 화면에 나오지 않는다.

## 2.6.0 해금·수집 보상

규칙은 모두 `data/unlocks.js`에서 바꾼다.
- **기체**: 별빛호는 처음부터, 드론호는 중간 보스 5종 모두 정화, 번개호는 **에듀이 + 드론호로 내포(폭주 AI 코어)를 클리어**하면 열린다(2.8.1부터, 예전 규칙으로 이미 연 학생은 그대로).
- **캐릭터**: 센터이는 SW·AI 개념 카드 6장 모두, 에듀이는 지역 상식 카드 5장 모두. 예전 규칙(공주·보령 클리어)으로 이미 연 학생은 그대로 열려 있다.
- **범주 완성 보상**(영구 능력치는 작게): 지역 상식 → 최대 체력 +8·칭호 충남 탐험가·노을 금색 / SW·AI 개념 → 공격력 +4%·코딩 박사·민트 회로 / 예방 수칙 → 받는 피해 -4%·안전 지킴이·분홍 하트 / AI 역량 → 경험치 +5%·AI 마스터·보라 별빛 / 33장 전부 → 필살기 충전 +8%·충남 수호대장·무지개.
- 칭호는 기지 위에, 범주 진행도·보상은 카드첩에, 기체 색은 출격 때 기체 선택 화면에서 고른다. 새로 열리면 축하 화면이 뜬다.

## 2.5.0에서 바뀐 것

- **카드첩 색깔**: 얻은 카드는 종류별 색(지역 상식 주황·SW·AI 개념 민트·예방 수칙 분홍·AI 역량 보라), 못 얻은 카드와 잠긴 이야기만 흑백. 지역 카드 그림은 흑백 원본에 지역별 색을 입힌 임시판(`tools/tint_landmarks.py`)이며, 컬러 그림을 받으면 그 PNG로 바꾼다.
- **몬스터 체력**: 일반 ×2, 중간 보스 ×2, 지역 보스 ×3, 최종 보스(폭주 AI 코어) ×4. 숫자는 `data/content.js`의 `HP_MULT`.
- **운의 요소**(`data/luck.js`에서 확률 조절): 도전 강화(레벨업, 등장 25%·성공 65%, 실패하면 이번엔 효과 없음), 흔들리는 제단(내용을 숨긴 가호, 영웅 16%), 보스 패턴 무작위·보스 분노(체력 절반 이하에서 35%), 웨이브 돌발 상황(20%: 유성우·정예 출현·보급 상자), 갈림길 결과 폭(코인 1.5~3.5배 등). 확률은 모두 화면에 보이고, 실패해도 가진 것은 잃지 않는다. 결과 화면에 도전 강화 성공 횟수와 확률이 남는다.

## 2.3.0에서 추가된 것

- **넓은 화면 정보 패널**: PC·전자칠판처럼 가로로 넓은 화면에서는 게임 양옆에 패널이 뜬다. 전투 중 왼쪽은 지역 진행·수호신 가호·12지신 동료, 오른쪽은 남은 수업 시간·이번 판 카드·조작법. 세로 기기는 그대로다 (`src/side.js`).
- **섬광 줄이기**: 설정과 일시정지 메뉴에서 켠다. 화면 번쩍임·흔들림·경고 깜빡임·번개 떨림을 약하게 한다.
- **체험관 모드**(교사 모드 설정): 공용 기기용. 게임을 새로 열 때마다 학생 기록이 처음 상태로 돌아가고, 결과 화면에 '다음 친구에게 넘기기' 버튼이 생긴다. 설정은 유지된다. 교사 모드의 '다음 학생 준비'는 기록만 지우고 교사 모드를 끈다.
- **정화 퀴즈 3문항**: 보스마다 OX 3문항 중 하나가 무작위로 나온다 (`data/extras.js`의 `QUIZ`).
- **수업 마무리 복습**: 수업 시간 모드가 끝나면 그날 얻은 카드로 OX 3문제를 풀고 결과 화면에 점수를 보여 준다. 카드가 모자라면 전에 모은 카드, 예방 수칙 카드 순으로 채운다 (`CARD_QUIZ`).

## 적·보스 탄 그림 (2.3.3)

적과 보스가 쏘는 탄은 쏜 쪽에 맞는 모양으로 그린다 (`src/bullet-art.js`). 판정 크기와 색 계열은 예전과 같다.
무한스크롤러는 좋아요 하트·재생 버튼·알림 종, 대필봇은 숙제 종이·종이비행기, 피싱 문어는 링크 사슬·낚싯바늘, 폭주 AI 코어는 0·1 데이터 조각과 붉은 눈처럼 각 교육 현안을 나타낸다. 모양은 한 번 그려 두고 재사용한다.
