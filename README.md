# 충남 수호대 — 코딩 블라스터

충남 지역과 교육 현안을 배경으로 한 세로형 슈팅 로그라이크 웹 게임입니다. 초·중학생 수업·체험용으로 만들었습니다.

- 파일럿 3명 × 기체 3종, 아산 → 공주 → 부여 → 보령 → 내포 5지역
- 충남 6수호신(계룡·금강·서해·백제·칠갑·태안)의 가호 30종, 듀오 10종, 전설 6종
- 교육 현안 보스 10종, 처치하면 예방 수칙 카드
- 손을 떼면 슬로우 모션, 제단마다 이어하기 저장, 교사 모드

## 실행

ES 모듈을 쓰므로 파일을 더블클릭하면 열리지 않습니다. 아래 중 하나로 여세요.

- GitHub Pages: 저장소 Settings → Pages → 브랜치 `main` / 폴더 `/(root)`
- 내 컴퓨터: 이 폴더에서 `python -m http.server` 실행 후 http://localhost:8000

## 조작

| 기기 | 이동 | 슬로우 | 필살기 | 일시정지 |
|---|---|---|---|---|
| 터치 | 드래그 | 손 떼기 | 오른쪽 아래 버튼 | 왼쪽 위 버튼 |
| PC | 마우스 드래그 또는 방향키·WASD | 손 떼기 / 키 놓기 | Space | Esc |

## 그림·소리 넣기

`docs/chatgpt-brief.md`의 파일 이름 그대로 `assets/img/`에 PNG를 넣으면 다음 실행부터 자동으로 바뀝니다. 없는 그림은 코드로 그린 임시 그림을 씁니다. 배경음은 `assets/bgm/bgm_title.mp3`, `bgm_base`, `bgm_battle`, `bgm_altar` 이름으로 넣습니다.

## 교사 모드

설정 탭 맨 아래 버전 글자를 7번 누르고 비밀번호 `cnsw2026`을 입력하면 모든 파일럿·난이도·카드가 열리고 시작 지역을 고를 수 있습니다. 학생 기록은 바뀌지 않습니다. 비밀번호는 `src/save.js`의 `TEACHER_CODE`에서 바꿉니다.
