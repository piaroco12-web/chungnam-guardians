# 충남 수호대 — 코딩 블라스터

충남 지역과 교육 현안을 배경으로 한 세로형 슈팅 로그라이크 웹 게임입니다. 초·중학생 수업·체험용으로 만들었습니다.

- 파일럿 3명 × 기체 3종, 아산 → 공주 → 부여 → 보령 → 내포 5지역
- 충남 6수호신(계룡·금강·서해·백제·칠갑·태안)의 가호 30종, 듀오 10종, 전설 6종
- 교육 현안 보스 10종, 처치하면 예방 수칙 카드
- 중간 보스 뒤 AI 12지신 동료 3택1, 웨이브 사이 갈림길, 정예 적과 보물 상자
- 보스 정화 OX 퀴즈, 오늘의 도전, 도전 계약, 이야기 조각 15개
- 수업 시간 모드, 설치형(오프라인) 실행
- 손을 떼면 슬로우 모션, 제단마다 이어하기 저장, 교사 모드

## 이미지·음원 완성본 2.2.0

- 게임 그림 83장: 파일럿·기체·6수호신·가호·보스 원본과 정화 모습·12지신·5지역·기지·계약·이야기 15장·UI.
- 배경음 8개(전투 2개 포함), 효과음 18개를 실제 화면 흐름에 연결했다. 배포 음원은 모두 CC0이며 출처는 설정 → 만든 사람들에서 볼 수 있다.
- 한글·기호 글꼴을 포함한다. 처음 온라인으로 완전히 내려받은 뒤에는 그림·음악도 오프라인 캐시에 저장된다. 사파리·안드로이드에서 실제 설치 버튼 표시는 기기별로 다를 수 있다.
- Windows는 `start_game.bat`, 그 외에는 `python start_game.py` 실행. 브라우저가 열리고, 실행 창을 닫으면 로컬 서버가 종료된다. Python 3가 필요하다.
- 새 버전에서 저장하는 진행 기록 키는 기존과 같다. 기기·브라우저별 기록은 해당 기기에 남는다.

## 그림·소리 넣기

게임 그림은 **WebP**(투명 배경 유지)로 `assets/img/`에 있고, 원본 PNG는 `art-src/img/`에 보관합니다(게임은 내려받지 않음). 첫 접속 용량은 약 26MB입니다.

새 그림은 `docs/chatgpt-brief.md`의 파일 이름 그대로 PNG를 `assets/img/`에 넣은 뒤 **`python tools/to_webp.py`를 한 번 실행**하세요. WebP로 바꾸고, 원본을 `art-src/img/`로 옮기고, 오프라인 목록(`assets/precache.json`)과 그림 목록을 맞춥니다. 그다음 `sw.js`와 `src/ui.js`의 VERSION을 올립니다. 바꾸기 전 PNG도 게임은 읽지만 오프라인 저장에서 빠집니다. 없는 그림은 코드로 그린 임시 그림을 씁니다.

수호신 가호 스킬 그림은 `boon_fx_sheet`(6×2)입니다. 윗줄은 궤도(뇌운 구슬·서리 칼날·소용돌이·불새 깃털·바람개비·빛 구슬), 아랫줄은 자동 스킬(낙뢰·서리꽃·해일·봉황 불새·칠갑 회오리·등대 불빛)이며, 수호신 순서(계룡·금강·서해·백제·칠갑·태안)대로 놓습니다. 완성본은 `assets/audio-manifest.json`에 있는 MP3 파일을 `src/audio.js`에서 연결합니다. 곡을 바꿀 때는 해당 매핑과 출처도 함께 수정합니다.

## 그림 정리 도구

ChatGPT가 만든 그림을 한 폴더에 모아 두고 아래를 실행하면, 이름을 게임 파일명으로 맞추고 흰 배경을 지우고 여백·크기를 정리해 `assets/img/`에 WebP로 넣어 줍니다(원본 PNG는 `art-src/img/`). 오프라인 목록은 `python tools/to_webp.py`로 맞춥니다. 아이콘 시트는 칸 간격이 고르지 않아도 같은 크기 칸으로 다시 맞춥니다.

```
pip install pillow
python tools/prepare_images.py 받은그림폴더          # 정리해서 저장
python tools/prepare_images.py 받은그림폴더 --dry    # 결과만 미리 보기
```

파일 이름은 `충남이.png`, `무한스크롤러.png`, `계룡 가호.png`처럼 한글 이름이어도 알아봅니다.

## 2.6.0 해금·수집 보상

규칙은 모두 `data/unlocks.js`에서 바꾼다.
- **기체**: 별빛호는 처음부터, 드론호는 중간 보스 5종 모두 정화, 번개호는 지역 보스 5종(최종 보스 폭주 AI 코어 포함) 모두 정화.
- **캐릭터**: 센터이는 SW·AI 개념 카드 6장 모두, 에듀이는 지역 상식 카드 5장 모두. 예전 규칙(공주·보령 클리어)으로 이미 연 학생은 그대로 열려 있다.
- **범주 완성 보상**(영구 능력치는 작게): 지역 상식 → 최대 체력 +8·칭호 충남 탐험가·노을 금색 / SW·AI 개념 → 공격력 +4%·코딩 박사·민트 회로 / 예방 수칙 → 받는 피해 -4%·안전 지킴이·분홍 하트 / AI 역량 → 경험치 +5%·AI 마스터·보라 별빛 / 33장 전부 → 필살기 충전 +8%·충남 수호대장·무지개.
- 칭호는 기지 위에, 범주 진행도·보상은 카드첩에, 기체 색은 출격 때 기체 선택 화면에서 고른다. 새로 열리면 축하 화면이 뜬다.

## 2.5.0에서 바뀐 것

- **카드첩 색깔**: 얻은 카드는 종류별 색(지역 상식 주황·SW·AI 개념 민트·예방 수칙 분홍·AI 역량 보라), 못 얻은 카드와 잠긴 이야기만 흑백. 지역 카드 그림은 흑백 원본에 지역별 색을 입힌 임시판(`tools/tint_landmarks.py`)이며, 컬러 그림을 받으면 그 PNG로 바꾼다.
- **몬스터 체력**: 일반 ×2, 중간 보스 ×2, 지역 보스 ×3, 최종 보스(폭주 AI 코어) ×4. 숫자는 `data/content.js`의 `HP_MULT`.
- **운의 요소**(`data/luck.js`에서 확률 조절): 도전 강화(레벨업, 등장 25%·성공 65%, 실패하면 이번엔 효과 없음), 흔들리는 제단(내용을 숨긴 가호, 영웅 16%), 보스 패턴 무작위·보스 분노(체력 절반 이하에서 35%), 웨이브 돌발 상황(20%: 유성우·정예 출현·보급 상자), 갈림길 결과 폭(코인 1.5~3.5배 등). 확률은 모두 화면에 보이고, 실패해도 가진 것은 잃지 않는다. 결과 화면에 도전 강화 성공 횟수와 확률이 남는다.

## 2.3.0에서 추가된 것

- **넓은 화면 정보 패널**: PC·전자칠판처럼 가로로 넓은 화면에서는 게임 양옆에 패널이 뜬다. 전투 중 왼쪽은 지역 진행·수호신 가호·12지신 동료, 오른쪽은 남은 수업 시간·이번 판 카드·조작법. 세로 기기는 그대로다 (`src/side.js`).
- **섬광 줄이기**: 설정과 일시정지 메뉴에서 켠다. 화면 번쩍임·흔들림·경고 깜빡임·번개 떨림을 약하게 한다.
- **체험관 모드**(교사 모드 설정): 공용 기기용. 게임을 새로 열 때마다 학생 기록이 처음 상태로 돌아가고, 결과 화면에 '다음 친구에게 넘기기' 버튼이 생긴다. 설정은 유지된다. 교사 모드의 '다음 학생 준비'는 기록만 지우고 교사 모드를 끈다.
- **정화 퀴즈 3문항**: 보스마다 OX 3문항 중 하나가 무작위로 나온다 (`data/extras.js`의 `QUIZ`).
- **수업 마무리 복습**: 수업 시간 모드가 끝나면 그날 얻은 카드로 OX 3문제를 풀고 결과 화면에 점수를 보여 준다. 카드가 모자라면 전에 모은 카드, 예방 수칙 카드 순으로 채운다 (`CARD_QUIZ`).

## 적·보스 탄 그림 (2.3.3)

적과 보스가 쏘는 탄은 쏜 쪽에 맞는 모양으로 그린다 (`src/bullet-art.js`). 판정 크기와 색 계열은 예전과 같다.
무한스크롤러는 좋아요 하트·재생 버튼·알림 종, 대필봇은 숙제 종이·종이비행기, 피싱 문어는 링크 사슬·낚싯바늘, 폭주 AI 코어는 0·1 데이터 조각과 붉은 눈처럼 각 교육 현안을 나타낸다. 모양은 한 번 그려 두고 재사용한다.
